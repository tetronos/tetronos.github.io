A private mesh network and a terminal desktop to use it.

tetron joins your machines into one encrypted peer-to-peer network, wherever they are. The tetron suite adds a terminal desktop, a web dashboard, a browser and add-ons around it. TetronOS puts it all on a GUI-less Debian system.

Install

Pick tetron or tetron-wm when it asks (Linux and macOS):

curl -fsSL https://tetronos.github.io/install.sh | bash

Or go straight to one. tetron, the mesh VPN, and its add-ons:

curl -fsSL https://tetronos.github.io/tetron/install.sh | bash

tetron-wm, the terminal desktop, with its recommended tools:

curl -fsSL https://tetronos.github.io/tetron-wm/install.sh | bash

Read before you run: install.sh, tetron installer, tetron-wm installer.

Add the apt repo

Debian 12+ and Ubuntu 22.04+ (amd64, arm64): signed packages of the whole suite, upgraded with the rest of the system by apt upgrade. Install tetron-wm, tetron, tetron-tui, tetron-webui or any other package listed at the tetronos apt repository.

sudo curl -fsSLo /usr/share/keyrings/tetronos-archive-keyring.gpg https://tetronos.github.io/apt/tetronos-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/tetronos.sources https://tetronos.github.io/apt/tetronos.sources
sudo apt update
sudo apt install tetron-wm

Each project's page has the other ways to install it (release binaries, cargo).
