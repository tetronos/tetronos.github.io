TetronOS v0.15.8 beta: Debian and NixOS

TetronOS: a whole computer, drawn in text.

A Linux system with no X11 and no Wayland. It boots into a truecolor console with a mouse and a real desktop: windows, a taskbar, an app store, a web browser, and tetron, a private mesh network that joins all your machines. It comes in two flavors with the same desktop and the same mesh: pick the base you prefer.

Debian flavor

Debian 13 made of ordinary signed .deb packages you can read, rebuild and replace, upgraded by apt upgrade.

Download Server (490 MB)Desktop (1.6 GB)

Server is the main edition: the console desktop, the mesh, the app store and drive mounting; add any app from the store. Desktop adds firmware, sound, the browser and the app collections, for a laptop that should just work. Release notes, SHA256 and how to write it to USB on the TetronOS page.

NixOS flavor

NixOS built from one flake: the whole system is declared in a file, every change is a new generation you can roll back.

Download the NixOS ISO (778 MB)

A server-style live system with the installer. Release notes and SHA256, source at tetron-nixos.

Beta. amd64, BIOS and UEFI. Write an ISO to USB with dd or Ventoy, or boot it in a VM. About TetronOS

tetron: the mesh that connects it all.

tetron is the core of TetronOS and of every tool here. It joins your laptop, servers, home machines and phone into one encrypted peer-to-peer network, wherever they are: at home, at work, behind NAT, on mobile data. No account, and no central server in the path of your traffic.

Invite only

Create a network, mint an invite key, join from the other machine. Invites are single-use and expire after 7 days by default.

Direct and encrypted

Peers connect straight to each other over QUIC, punching through NAT with iroh; a relay only helps them find each other, or carries encrypted traffic when no direct path exists.

Stable addresses

Each machine gets a stable IPv4 and IPv6 address in every network, derived from its identity. ssh, file shares, web apps: any TCP or UDP program works.

Many networks, kept apart

Each network gets its own interface and subnet. Co-coordinators keep it running when one machine is off; Tor and self-hosted relays are options.

On TetronOS it is installed and ready; the tetron-wm tray shows your peers. Anywhere else: curl -fsSL https://tetronos.github.io/tetron/install.sh | bash

Not installing TetronOS? Keep your own Linux, NixOS or macOS and add the parts you want. Everything below installs on the system you already have; TetronOS comes with all of it.

tetron joins your machines into one encrypted peer-to-peer network, wherever they are. The tetron suite adds a terminal desktop, a web dashboard, a browser and add-ons around it. TetronOS puts it all on a GUI-less Debian or NixOS system; every part also installs on the computer you have.

Install the suite

Pick tetron or tetron-wm when it asks (Linux and macOS):

curl -fsSL https://tetronos.github.io/install.sh | bash

Or go straight to one. tetron, the mesh VPN, and its add-ons:

curl -fsSL https://tetronos.github.io/tetron/install.sh | bash

tetron-wm, the terminal desktop, with its recommended tools:

curl -fsSL https://tetronos.github.io/tetron-wm/install.sh | bash

Read before you run: install.sh, tetron installer, tetron-wm installer.

Add the apt repo

Debian 12+ and Ubuntu 22.04+ (amd64, arm64): signed packages of the whole suite, upgraded with the rest of the system by apt upgrade. Install tetron-wm, tetron, tetron-tui, tetron-webui or any other package listed at the tetronos apt repository.

sudo curl -fsSLo /usr/share/keyrings/tetronos-archive-keyring.gpg https://tetronos.github.io/apt/tetronos-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/tetronos.sources https://tetronos.github.io/apt/tetronos.sources
sudo apt update
sudo apt install tetron-wm

Nix and NixOS

Any Linux with Nix, or NixOS (x86_64 and aarch64): each part of the suite is a package and a NixOS module of the tetron-nixos flake, on stock nixpkgs. Try one, or install it to your profile:

nix run github:tetronos/tetron-nixos#casttui
nix profile install github:tetronos/tetron-nixos#tetron-tui

Packages: tetron, tetron-wm, tetron-tui, casttui, kmscon. On NixOS add the flake as an input and turn on only the modules you want; nothing else on the machine changes:

modules = [
  tetron-nixos.nixosModules.tetron
  tetron-nixos.nixosModules.tetron-tui
  { services.tetron = { enable = true; operator = "alice"; };
    programs.tetron-tui.enable = true; }
];

A signed binary cache saves compiling them. Add it to /etc/nix/nix.conf (then restart nix-daemon), or to nix.settings on NixOS:

extra-substituters = https://github.com/tetronos/tetron-nixos-cache/releases/download/cache
extra-trusted-public-keys = tetron-nixos-cache-1:VZnNn/Hb0ytcL354uHPmQeZA0CZheIIHUgjBVrghLUI=

The modules, the whole-system module and the cache are described in the tetron-nixos README.

Each project's page has the other ways to install it (release binaries, cargo).
